# README requirements

## Audience and focus

- Address visitors and contributors of the Awesome Site at https://awesome.hagicode.com, which hosts community-curated "awesome" collections in ten reading languages.
- Lead with the value for readers (less searching, more discovering) before any build detail.

## Required content

- Keep the highlights, a quick start of three steps or fewer, requirements and install, data submodule, locales and homepages, content commands, build and publication, as the current README does.
- Keep collection and language counts consistent with `data/` and the locale configuration.

## Exclusions

- Exclude analytics identifiers, tokens, secret values, internal hosts, machine-specific paths and private links.
- Do not describe features the site does not show.
