## 数据分析

 *数据分析平台、SDK、错误追踪，以及关于你的应用的实时解答*

- [Answers by Fabric](https://get.fabric.io) - Answers 让你实时洞察用户在你的应用中的使用体验。
- [Aptabase](https://aptabase.com/for-swift) - 面向 Swift 应用的开源、隐私优先且简单易用的数据分析工具。
- [Bugsnag](https://www.bugsnag.com/platforms/ios-crash-reporting) - 提供免费套餐的错误追踪服务。错误报告包含设备、版本发布和用户等数据，并允许附加任意数据。
- [Countly](https://count.ly) - 面向 iOS 和 Android 的开源移动与 Web 分析、崩溃报告及推送通知平台。
- [devtodev](https://www.devtodev.com/) - 全面的数据分析服务，可帮助改进你的项目并节省产品开发时间。
- [Embrace](http://embrace.io) - 基于 OpenTelemetry 构建的移动端可观测性平台，助你打造以用户为中心、稳定可靠的应用。
- [Emerge Tools](https://www.emergetools.com) - 在每个拉取请求中防止应用体积和性能退化，并自动获得关于如何改进的洞察。
- [Instabug](https://instabug.com) - 应用内反馈、Bug 与崩溃报告；借助用户操作步骤、录屏、屏幕标注和网络请求日志更快地修复 Bug。
- [Matomo](https://github.com/matomo-org/matomo-sdk-ios) - MatomoTracker 是一个适用于 iOS、tvOS 和 macOS 的 SDK，用于将应用分析数据发送到 Matomo 服务器。
- [Measure](https://measure.sh/) - 开源、可自托管的移动应用监控工具，提供错误追踪、性能追踪和完整的会话时间线，让你少花时间拼凑上下文，更快地修复问题。
- [Mixpanel](https://mixpanel.com/) - 高级数据分析平台。
- [MOCA Analytics](https://www.mocaplatform.com/features) - 付费的跨平台数据分析后端。
- [Segment](https://github.com/segmentio/analytics-ios) - 将数据分析集成到任意 iOS 应用中的省心方案。
- [Sentry](https://sentry.io/) - Sentry 提供自托管和云端的错误监控，帮助各类软件团队实时发现、分类错误并确定其优先级。
- [Shake](https://www.shakebugs.com/) - 应用内反馈与 Bug 报告工具。借助详细的设备数据、复现步骤、录屏、黑匣子数据、网络请求和自定义日志，修复应用 Bug 的速度最多可提升 50 倍。

## 应用路由

  *优雅的 URL 路由、导航框架、深度链接等*

- [ApplicationCoordinator](https://github.com/AndreyPanov/ApplicationCoordinator) - Coordinator 是一个负责处理导航流程的对象，在切换到下一个链路后，它会将流程的处理工作交给下一个 coordinator。
- [Appz](https://github.com/SwiftKitz/Appz) - 轻松启动外部应用并通过深度链接跳转，若应用未安装则回退到网页。
- [Composable Navigator](https://github.com/Bahn-X/swift-composable-navigator) - 一个用于构建支持深度链接的 SwiftUI 应用的开源库，在设计上兼顾了可组合性、可测试性和易用性
- [Crossroad](https://github.com/giginet/Crossroad) - Crossroad 是一个专注于处理自定义 URL Scheme 的 URL 路由器。使用它，你可以轻松地路由多种 URL Scheme 并获取参数。
- [DeepLinkKit](https://github.com/button/DeepLinkKit) - 一种出色的、基于 block 的路由匹配方式，用于处理你的深度链接。
- [JLRoutes](https://github.com/joeldev/JLRoutes) - 适用于 iOS 的 URL 路由库，提供简单的基于 block 的 API。
- [Linker](https://github.com/MaksimKurpa/Linker) - 在 iOS 中处理内部和外部深度链接的轻量级方案。
- [Marshroute](https://github.com/avito-tech/Marshroute) - Marshroute 是一个 iOS 库，能让你的路由器简单却极其强大。
- [RouteComposer](https://github.com/ekazaev/route-composer) - 帮助处理视图控制器组合、路由和深度链接任务的库。
- [RxFlow](https://github.com/RxSwiftCommunity/RxFlow) - 基于响应式流程协调器（Reactive Flow Coordinator）模式的 iOS 应用导航框架。
- [SwiftCurrent](https://github.com/wwt/SwiftCurrent) - 一个用于管理复杂工作流的库。
- [SwiftRouter](https://github.com/skyline75489/SwiftRouter) - 一个适用于 iOS 的 URL 路由器。
- [URLNavigator](https://github.com/devxoul/URLNavigator) - 优雅的 Swift URL 路由
- [WAAppRouting](https://github.com/Wasappli/WAAppRouting) - 正确实现的 iOS 路由。同时处理 URL 识别以及携带解析后参数的控制器展示。只需一行代码，并自动保留控制器栈！

## 架构模式

*整洁架构、Viper、MVVM、响应式……选择你的武器吧。*

- [Clean Architecture for SwiftUI + Combine](https://github.com/nalexn/clean-architecture-swiftui) - 一个演示项目，展示了采用整洁架构（Clean Architecture）的 SwiftUI 应用在生产环境中的配置。
- [CleanArchitectureRxSwift](https://github.com/sergdort/CleanArchitectureRxSwift) - 使用 RxSwift 实现整洁架构的 iOS 应用示例。
- [ios-architecture](https://github.com/tailec/ios-architecture) - iOS 架构合集——MVC、MVVM、MVVM+RxSwift、VIPER、RIBs 等等。
- [iOS-Viper-Architecture](https://github.com/MindorksOpenSource/iOS-Viper-Architecture) - 该仓库包含一个详细的示例应用，它使用 Alamofire、AlamofireImage、PKHUD、CoreData 等库和框架在 iOS 中实现了 VIPER 架构。
- [Reactant](https://github.com/Brightify/Reactant) - Reactant 是一种适用于 iOS 的响应式架构。
- [Spin](https://github.com/Spinners/Spin.Swift) - 适用于 RxSwift、ReactiveSwift 和 Combine 的反馈循环（Feedback Loop）系统的通用实现
- [SwiftyVIPER](https://github.com/codytwinton/SwiftyVIPER) - 让 VIPER 架构的实现更加简单、整洁。
- [The Composable Architecture](https://github.com/pointfreeco/swift-composable-architecture) - The Composable Architecture 是一个以一致且易于理解的方式构建应用的库，在设计上兼顾了可组合性、可测试性和易用性。
- [Viperit](https://github.com/ferranabello/Viperit) - 适用于 iOS 的 Viper 框架。以简单的方式开发遵循 VIPER 架构的应用。使用 Swift 编写并测试。

## 图表

*探索美观、易用且可自定义的 iOS 图表库，非常适合创建动态而惊艳的数据可视化效果。*

- [ANDLineChartView](https://github.com/anaglik/ANDLineChartView) - ANDLineChartView 是一个简单易用、基于视图的类，用于显示带动画的折线图。
- [Charts](https://github.com/danielgindi/Charts) - 一个强大的图表框架，相当于 iOS 版的 [MPAndroidChart](https://github.com/PhilJay/MPAndroidChart)。
- [core-plot](https://github.com/core-plot/core-plot) - 一个高度可定制的 2D 绘图库，能够绘制多种类型的图表。
- [EatFit](https://github.com/Yalantis/EatFit) - Eat fit 是一个受 Google Fit 启发、用于美观地展示数据的组件。
- [EChart](https://github.com/zhuhuihuihui/EChart) - 适用于 iOS/iPhone/iPad 的图表组件，支持事件处理和动画。
- [FSInteractiveMap](https://github.com/ArthurGuibert/FSInteractiveMap) - 一个在 iOS 上可视化矢量地图并与之交互的图表库。它就像 iOS 版的 Geochart。
- [FSLineChart](https://github.com/ArthurGuibert/FSLineChart) - 一个适用于 iOS 的折线图库。
- [JBChartView](https://github.com/Jawbone/JBChartView) - 基于 iOS 的图表库，同时支持折线图和柱状图。
- [JYRadarChart](https://github.com/johnnywjy/JYRadarChart) - 一个开源的 iOS 雷达图实现。
- [MagicPie](https://github.com/AlexandrGraschenkov/MagicPie) - 出色的基于 layer 的饼图。速度极快且完全可定制。MagicPie 还提供令人惊叹的动画效果。
- [PieCharts](https://github.com/i-schuetz/PieCharts) - 简单易用且高度可定制的 iOS 饼图库。
- [PNChart](https://github.com/kevinzhow/PNChart) - 一个简单美观的 iOS 图表库，被用于 Piner 和 CoinsMan 中。
- [Scrollable-GraphView](https://github.com/philackm/ScrollableGraphView) - 一个适用于 iOS 的自适应可滚动图表视图，用于可视化简单的离散数据集。使用 Swift 编写。

- [TEAChart](https://github.com/xhacker/TEAChart) - 简单直观的 iOS 图表库，支持贡献图、时钟图和柱状图。
- [TKRadarChart](https://github.com/TBXark/TKRadarChart) - 一个使用 Swift 编写的可自定义雷达图。
- [TWRCharts](https://github.com/chasseurmic/TWRCharts) - ChartJS 的 iOS 封装。借助原生 Obj-C 代码的能力轻松构建带动画的图表。
